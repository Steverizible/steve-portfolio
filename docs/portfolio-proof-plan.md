# Portfolio Proof Plan

Use this checklist when replacing temporary illustrations with real, redacted evidence.

For every proof slot:

- Document page + section
- What image belongs there
- Recommended dimensions
- What the image proves
- Status: Real / Redacted / Illustrative / Temporary
- What must be blurred or removed
- File naming recommendation
- Replacement priority (P1–P3)

## Shared privacy rules

Never publish:

- Customer names, emails, phones
- Order-level data
- API keys / tokens
- Private Airtable / Figma / Shopify / Klaviyo URLs
- Credentials
- Unapproved internal revenue details
