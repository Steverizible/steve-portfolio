---

## 1. Klaviyo Performance Evidence

Use a real redacted performance report.

Show:

- Campaign or flow labels
- Approved aggregate results
- Channel comparisons
- Performance trends

Hide:

- Customer data
- Account identifiers
- Order-level information
- Private financial details
- Credentials

---

## 2. Shopify Verification Evidence

Show:

- Approved products
- Inventory status
- Product links
- Sale eligibility

Hide:

- Private admin details
- Customer information
- Vendor costs
- Credentials

---

## 3. Airtable Campaign Record

Show:

- Campaign objective
- Phase
- Audience
- Products
- Copy
- Creative status
- Review status
- Results
- Next action

Hide:

- Private base links
- Personal details
- Internal IDs
- Confidential notes

---

## 4. Figma Wireframe

Show:

- Email hierarchy
- Product modules
- Mobile layout
- Desktop layout
- Design notes
- Review state

Use a real redacted wireframe where possible.

---

## 5. Klaviyo Draft

Show:

- Draft status
- Campaign name
- Subject line
- Audience summary
- Creative preview

Do not show:

- Send controls in a way suggesting autonomous sending
- Private segment membership
- Customer details
